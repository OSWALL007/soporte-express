## Cambios incluidos

- Rediseño responsive y más competitivo.
- Sección con 7 reseñas reales de Google.
- Indicador de confianza: 5.0 estrellas y 7 opiniones.
- Servicios ampliados: reparación, SSD, mantenimiento, domicilio, remoto y CCTV.

- Metadatos Open Graph, canonical, favicon y robots.
- `sitemap.xml` y `robots.txt`.
- Página específica de reparación de laptops actualizada.

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Sube todos los archivos a la raíz del repositorio `soporte-express`.
3. Reemplaza los archivos anteriores cuando GitHub lo solicite.
4. Espera entre 1 y 5 minutos y abre:
   `https://oswall007.github.io/soporte-express/`
